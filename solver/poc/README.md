# solver PoC — CP-SAT 実現性検証

[制約仕様書 v0.1](../../docs/constraint-spec.md) のうち **H0–H6・S1/S4/S5/S6** を最小実装し、
小規模インスタンス（5名 × 14日）で数秒以内に解けることを確認する PoC。

## 実行

```bash
cd solver
pip install -r requirements.txt   # ortools
python -m poc.run_poc
```

## 構成

| ファイル | 役割 |
| :---- | :---- |
| `dummy_data.py` | 5名×14日の決定論的ダミーインスタンス（本番は Pydantic 入力 + DB に置換） |
| `shift_model.py` | CP-SAT モデル構築・求解。制約番号（H1, S5 等）を仕様書と対応付け |
| `run_poc.py` | 実行エントリ。シフト表と個人別集計を表示 |

## 実装済みの制約（仕様書との対応）

| 制約 | 内容 | 実装 |
| :---- | :---- | :---- |
| H0/H0' | 1日1パターン・勤務可能性 | ✅ |
| H1/H1' | 役職別・スキル別の必要人数 | ✅ |

| H6 | ハードNGペア同時出勤禁止 | ✅ |
| S1 | 土日出勤の平準化 | ✅（目的項） |
| S4 | 推奨/OJTペア同時出勤（加点） | ✅（目的項） |
| S5 | ソフトNGペア同時出勤（減点） | ✅（目的項） |

## 検証結果（サンプル実行）

```
求解ステータス: OPTIMAL
求解時間      : 0.016 秒
土日出勤の偏り  : range = 0（完全平準化）
ソフトNG同時出勤: 0 回
推奨ペア同時出勤: 9 回
希望勤務の充足  : 5 件
```

5名×14日で全ハード制約を満たす最適解を **0.02 秒未満** で取得。要件の性能目標
（15名×31日を10秒以内）に対し、本アプローチ（CP-SAT）の実現性を確認した。
